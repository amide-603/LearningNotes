世界模型在自动驾驶中的核心作用，是根据当前场景和可能的驾驶动作，预测“接下来会发生什么”。 它预测的对象可以是**视频、点云、三维占用空间、其他车辆的运动，也可以是供规划器使用的压缩状态**。

## 世界模型在自动驾驶系统中的作用环节

| 应用           | 作用于什么环节  | 作用方式 | 世界模型具体做什么                                   | 代表论文                                                                                                                                                                |
| ------------ | -------- | ---- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 驾驶数据生成与增强    | 数据构建     | 离线开环 | 生成危险、偏离道路、罕见的驾驶视频，补充稀有场景                    | [Cosmos-Drive-Dreams，2025](https://arxiv.org/abs/2506.09042)、[GAIA-2，2025](https://arxiv.org/abs/2503.20523)                                                        |
| 感知预训练        | 感知       | 离线开环 | 用“预测未来特征”作为训练目标，学习时空动态，减少对密集感知标注的依赖         | [DriveWorld，CVPR 2024](https://arxiv.org/abs/2405.04390)、[LAW，ICLR 2025](https://arxiv.org/abs/2406.08481)                                                          |
| 未来占据预测       | 预测       | 在线开环 | 预测未来视频、BEV、3D 占据或潜变量                        | [OccWorld，ECCV 2024](https://arxiv.org/abs/2311.16038)、[Vista，NeurIPS 2024](https://arxiv.org/abs/2405.17398)                                                       |

| 联合生成轨迹       | 端到端决策/规划 | 在线闭环 | 联合预测未来场景与自车动作，或把预测的未来潜变量输入策略；世界模型参与“怎么开”的生成 | [MILE，NeurIPS 2022](https://arxiv.org/abs/2210.07729)、[DriveWorld-VLA，2026 预印本](https://arxiv.org/abs/2602.06521)                                                   |

| 交互式闭环仿真      | 仿真、评测    | 离线闭环 | 接收驾驶策略动作，生成下一步传感器观测，辅助规划                    | [CausalDrive，2026 预印本](https://arxiv.org/abs/2606.15341)，报告了闭环评测、RL 后训练和人参与的交互仿真                                                                                    |

Q：世界模型用于**候选动作评价**(如 Wote、World4Drive、DA-WAM)时，这个时候相比交互式预测规划，优势是什么？

A：主要优势在于，**用紧凑的未来表征直接评价候选动作，更方便利用视觉数据、学习规划相关特征**
- 交互式预测规划：`候选自车轨迹 → 对应的周车响应 → 代价评价 → 选择/优化`
- 世界模型候选评价：`候选自车轨迹 → 对应的未来 BEV/潜变量 → 评分 → 选择`

更有依据的优势，可分为三点：

| 优势                            | 具体体现                                                                     | 成立边界                              |
| ----------------------------- | ------------------------------------------------------------------------ | --------------------------------- |
| 减少中间表示的瓶颈                     | 可以直接从潜变量$z_t$中提取评价所需的信息，不必轨迹解码、再构造代价                                     | 潜变量是否保留了关键危险信息，需要验证；交互预测也能使用占据表示  |
| 更方便利用未来视频和预训练的视频模型，减少人工感知标注需求 | 真实未来的编码可以提供自监督目标。World4Drive 用未来特征对齐、伪语义和估计深度学习表征；DA-WAM 将视频预训练表征适配到动作评价 | 降低的是部分人工感知标注需求；仍需要专家轨迹、伪标签或规划指标监督 |
| 在线推理压缩为并行预测评分                 | 相比需要多层相互响应、树搜索或迭代优化的实现，有限候选可以批量预测未来并打分                                   |                                   |
