世界模型在自动驾驶中的核心作用，是根据当前场景和可能的驾驶动作，预测“接下来会发生什么”。 它预测的对象可以是**视频、点云、三维占用空间、其他车辆的运动，也可以是供规划器使用的压缩状态**。

Q：世界模型用于**候选动作评价**(如 Wote、World4Drive、DA-WAM)时，这个时候相比交互式预测规划，优势是什么？

A：主要优势在于，**用紧凑的未来表征直接评价候选动作，更方便利用视觉数据、学习规划相关特征**
- 交互式预测规划：`候选自车轨迹 → 对应的周车响应 → 代价评价 → 选择/优化`
- 世界模型候选评价：`候选自车轨迹 → 对应的未来 BEV/潜变量 → 评分 → 选择`

更有依据的优势，可分为三点：

| 优势                            | 具体体现                                                                     | 成立边界                              |
| ----------------------------- | ------------------------------------------------------------------------ | --------------------------------- |
| 减少中间表示的瓶颈                     | 可以直接从潜变量$z_t$中提取评价所需的信息，不必轨迹解码、再构造代价                                     | 潜变量是否保留了关键危险信息，需要验证；交互预测也能使用占据表示  |
| 更方便利用未来视频和预训练的视频模型，减少人工感知标注需求 | 真实未来的编码可以提供自监督目标。World4Drive 用未来特征对齐、伪语义和估计深度学习表征；DA-WAM 将视频预训练表征适配到动作评价 | 降低的是部分人工感知标注需求；仍需要专家轨迹、伪标签或规划指标监督 |
| 在线推理压缩为并行预测评分                 | 相比需要多层相互响应、树搜索或迭代优化的实现，有限候选可以批量预测未来并打分                                   |                                   |
